# FLY Cinema AI — Clean Android Project

Clean GitHub-ready Android project for FLY Cinema AI.

## Build without Android Studio

1. Create a new empty GitHub repository.
2. Upload the contents of this ZIP to the repository root.
3. Open Actions.
4. Run **Build FLY Cinema APK**.
5. Open the completed workflow.
6. Download the **FLY-CINEMA-AI-debug** artifact.
7. Extract it and install `app-debug.apk` on Android.

## App

Package: `com.flyfmgh.flycinemaai`
Version: `1.0.0`

The app contains a local film-planning studio for long-form Ghanaian/Ghallywood-style projects: story/script planning, scene planning, voiceover preparation and publishing copy. It deliberately contains no private API keys. AI generation providers can be connected later.
