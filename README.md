# FLY Cinema AI Android App

Clean Android starter project designed for GitHub Actions APK builds.

## Build on GitHub
1. Upload the contents of this ZIP to your repository root.
2. Open **Actions**.
3. Select **Build FLY Cinema AI APK**.
4. Tap **Run workflow**.
5. After the job succeeds, open the run and download the **FLY-Cinema-AI-debug** artifact.

The project uses Gradle Kotlin DSL, Android Gradle Plugin 8.6.1 and Java 17.
